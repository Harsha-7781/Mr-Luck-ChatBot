# 🤖 Mr.Luck – AI Chatbot

Mr.Luck is a full-stack AI chatbot inspired by ChatGPT, built using Flask and Google Gemini API, featuring a modern dark UI, chat history, markdown rendering, and code copy support.

## ✨ Features
- ChatGPT-style full-screen UI
- Light grey user query bubbles
- Markdown & code block rendering
- Copy button for code snippets
- Smooth message animations
- Chat history with sidebar
- Share conversations
- Dark theme UI

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- AI Model: Google Gemini API
